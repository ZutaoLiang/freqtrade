# OI 去杠杆冲击的反向交易：事件研究，否决（2026-09-06）

承接 `strategy-candidates-20260906.md` 的 C2。假说：30 分钟内价格极端移动（≥ 3σ）且持仓量（OI）
同时下降 ≥ X%，说明是强制平仓而非信息驱动，平仓压力停止后价格回归；OI 上升的极端移动则应延续。
`overshoot-reversion.md` 的量能版本已在训练段为负，本轮只是补上 OI 这个从未测过的条件。

## 冻结定义

- 5m 面板：本地 1m K 线重采样 + `binance_public/metrics` 的 5m OI；mark 价格 5m 收盘判定移动。
- 事件：`|mark[t]/mark[t−6] − 1| ≥ 3σ`，σ 为此前 7 天 30 分钟 mark 收益的标准差（右移 6 根）；
  `OI[t]/OI[t−6] − 1` 按 X ∈ {5%, 10%} 分为 OI_down / OI_flat / OI_up，再按移动方向分桶。
- 反向仓位：涨后做空、跌后做多，t+1 开盘入场，持有 5 / 15 / 30 / 60 / 240 分钟，
  算术收益，扣 20bp 往返；同币 60 分钟冷却；宇宙为前 30 日日成交额中位数 ≥ 1000 万（另报 ≥ 100 万）。
- 对照：BTC 同窗口同向反向仓位；按 4 小时日历块聚类 bootstrap；2025 训练 / 2026-01～05 验证 / 2026-06 起保留。
- 事先声明：只有"OI_down 桶显著为正且 OI_up 桶不为正"才算通过。

## 结果：全部反向桶为负

368,001 个事件、681 个币。宇宙 ≥ 1000 万、X = 5% 时，反向仓位净收益（bps，扣 20bp）：

| 桶 | n | 5m | 15m | 30m | 60m | 240m |
|---|---:|---:|---:|---:|---:|---:|
| OI 降 / 价跌 → 做多 | 1213 | −26 | −39 | −39 | −39 | −32 |
| OI 降 / 价涨 → 做空 | 448 | −4 | +17 | +87 | +1 | −35 |
| OI 平 / 价跌 → 做多 | 60470 | −19 | −15 | −24 | −10 | −14 |
| OI 平 / 价涨 → 做空 | 70009 | −18 | −16 | −17 | −19 | −22 |
| OI 升 / 价跌 → 做多 | 907 | −25 | −29 | −40 | −67 | −145 |
| OI 升 / 价涨 → 做空 | 3185 | −18 | −10 | −11 | −9 | −16 |

- **强平桶（OI 降 / 价跌）在所有持有期都为负**，且比 OI 平桶更差：去杠杆后的下跌是延续，不是过冲。
  bootstrap 区间上限在 60 分钟以内全部 < 0。
- OI 降 / 价涨（逼空）30 分钟 +87bps 是唯一为正的格，但 n = 448、区间 [−29, +178]、
  保留段 −137；X = 10% 时 +253bps、n = 120、区间 [−8, +417]、保留段 −188。不构成证据。
- 大多数格的中位数为正、均值为负：反向交易赢在小事件、输在尾部，尾部是延续的那一类。
- ≥ 100 万宇宙和 X = 10% 的完整表在 `user_data/oi_delever_20260906.log`，结构相同。
- BTC 对照均值在 ±10bps 内，市场方向不解释这些数字。

## 事后观察（不是预注册结论，不作为候选）

"OI 升 / 价跌"桶的 4 小时**顺势**做空均值 +105bps，但训练段 −3、验证段 +384、保留段 +54，
中位数 −13：只由 2026 上半年少数事件贡献。它在机制上是资金费偏斜策略的邻居（新空头涌入的下跌），
若要跟进，须另行冻结定义，不能从本表里挑格。

## 判定

C2 否决。OI 下降不把极端移动变成可回归的过冲；与 `overshoot-reversion.md` §0 的否决记录一致。
