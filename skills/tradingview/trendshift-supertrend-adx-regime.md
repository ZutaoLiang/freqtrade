## 2. 整体策略思路总结

### 2.1 核心指标

- `ta.dmi(14, 14)` 取 ADX。
- Supertrend `ta.supertrend(effectiveMult, 10)`，其中 `effectiveMult` 逐 K 线可变。

### 2.2 市场假设

用 ADX 判断"趋势/震荡"两种波动率状态，并据此调整 Supertrend 带宽：趋势里用窄带
（1.75×ATR）快速跟随，震荡里用宽带（4.5×ATR）减少假翻转；ADX 落在 20~25 的中间带时
**保持上一个状态**（滞回，避免抖动）。

### 2.3 入场 / 出场（原策略完整规则）

```
isTrending = adx > 25 ; isChoppy = adx < 20
regime     = isTrending ? "TRENDING" : isChoppy ? "CHOPPY" : regime[1]      // var 锁存
effectiveMult = regime=="TRENDING" ? 1.75 : regime=="CHOPPY" ? 4.5 : effectiveMult[1]

[stLine, stDir] = ta.supertrend(effectiveMult, 10)
bullFlip = change(stDir)!=0 and stDir==-1      // 翻多
bearFlip = change(stDir)!=0 and stDir== 1      // 翻空

entriesAllowed = not (isChoppy and disableChop)          // disableChop 默认 true
longSignal  = bullFlip and entriesAllowed
shortSignal = bearFlip and entriesAllowed

stopDist = abs(close - stLine)
qty      = equity * 1% / stopDist                        // riskPct 默认 1.0

if longSignal  and position<=0 and qty>0 : entry Long
if shortSignal and position>=0 and qty>0 : entry Short

if useTrailing and position>0 : exit(stop=stLine, limit=useTP ? avg+stopDist*2 : na)
if useTrailing and position<0 : exit(stop=stLine, limit=useTP ? avg-stopDist*2 : na)
if flattenOnChop and isChoppy and position!=0 : close_all
if maxBarsInTrade>0 and barsInTrade>=maxBarsInTrade : close_all
```

### 2.4 关键默认参数

| 参数 | 默认值 |
| --- | --- |
| `adxLen` / `adxSmooth` | 14 / 14 |
| `adxTrendTh` / `adxChopTh` | 25 / 20 |
| `atrLen` | 10 |
| `tightMult` / `wideMult` | 1.75 / 4.5 |
| `disableChop` | true |
| `flattenOnChop` | false |
| `useTrailing` | **false** |
| `useTP` / `rMultiple` | true / 2.0（但见下） |
| `maxBarsInTrade` | 0（关闭） |
| `riskPct` | 1.0 |
| 手续费 / 滑点 | 0.05% / 1 tick |
| 仓位 | `strategy.fixed`，被 `qty` 覆盖 |

### 2.5 源码中值得单独指出的四点

1. **默认配置下没有任何出场单。** 唯一的 `strategy.exit`（ST 追踪止损 + 2R 止盈）整个
   包在 `if useTrailing` 里，而 `useTrailing` 默认 false；`flattenOnChop` 默认 false，
   `maxBarsInTrade` 默认 0。所以默认行为是永远在市，只靠反向 `strategy.entry` 换向。
2. **反手即出场，于是 chop 闸门会把仓位卡住。** 翻转发生在 ADX<20 时反向入场被拦，
   已有仓位原地保留继续持有，而不是平仓观望。
3. **`useTP` 单独打开无效**，因为止盈挂在同一个 `strategy.exit` 上；且 TP 用**当前 K 线**的
   `stopDist` 而非入场时的，目标价逐 K 漂移。
4. **"1% 风险"名不副实。** `qty = equity*1% / stopDist`，BTC 1h 上允许开仓时刻的
   `stopDist/close` 中位数约 1.49%，即名义敞口约 0.67 倍权益；而默认无止损，
   所以 1% 只是名义标签，单笔实际亏损无上限。

### 2.6 本阶段纯信号实验的保留 / 移除

依据 `skills/tradingview/SKILL.md` §5：

| 原规则 | 本阶段 |
| --- | --- |
| ADX regime 锁存 + 滞回 | **保留** |
| regime 切换 Supertrend factor | **保留** |
| chop 入场闸门 `disableChop` | **保留**（属于信号条件） |
| Supertrend 翻转多空入场 | **保留** |
| 反向信号平仓 | **保留**（唯一出场） |
| ST 追踪止损 `useTrailing` | 移除（本就默认关闭） |
| 2R 止盈 `useTP` | 移除（本就默认失效） |
| `flattenOnChop` | 移除（默认关闭） |
| `maxBarsInTrade` | 移除（默认关闭） |
| `qty = 1% 风险 / stopDist` 仓位 | **移除**，改为矩阵统一的固定名义仓位 |

因此本阶段的纯信号版与"原策略默认配置"在出场上是一致的（原默认本来就无止损止盈），
差异只在仓位口径。这一点在结论中不得混淆为"移除了作者的风控"。

### 3.2 移植差异与实现说明

- **动态 factor Supertrend**：Pine `ta.supertrend` 在 factor 逐 K 变化时，band 棘轮仍与
  上一根（用旧 factor 算出的）band 比较。`supertrend_dynamic` 按此语义逐 K 循环实现，
  不是"每次换 factor 就重算整条线"。
- **ADX 口径**：Pine `ta.dmi(adxLen, adxSmooth)` 允许 DI 长度与 ADX 平滑分开；默认两者
  都是 14，本实现用 `talib.ADX(14)`（Wilder），与默认值等价。若日后改成不等长度，
  必须换成独立实现，此处标注为已知限制。
- **反手成交**：Pine 用一张反向 `strategy.entry` 完成换向；Freqtrade 需要"平仓 + 反向开仓"
  两笔，落在同一根 K 线开盘价上。手续费两侧都收，与 Pine 相同，但这是引擎差异而非等价，
  矩阵单元统计 `same_candle_flips` 报告同根换向实际发生次数。
- **出场绑定**：出场信号绑在**对侧入场条件**（含 chop 闸门）上，而不是裸翻转，
  以复刻 §2.5 第 2 点。
- **未修复的"源码问题"**：`useTP` 依赖 `useTrailing`、TP 用当前 K 线 `stopDist`、
  "1% 风险"实为约 0.67 倍名义敞口 —— 这些是作者的设计后果而非作用域错误，
  在忠实移植中原样保留，在纯信号版中因整体移除风控而不涉及。
- **无未来函数**：信号只用已收盘 K 线，下一根开盘成交（`process_only_new_candles`，
  市价单）。`lookahead-analysis` 对 `TrendShiftRegime` 已跑出 `has_bias = No`。

### 3.3 引擎残留保护（SKILL.md §5 要求披露）

- `minimal_roi = {}`：真正无 ROI 出场，不是设一个极远值。
- `stoploss = -0.99`：Freqtrade 必填字段，无法移除。每个单元单独统计
  `stop_loss` 出场笔数与 `liquidation` 笔数；任何一项非零的单元不得称为干净的纯信号结果。
- `trailing_stop=False`、`use_custom_stoploss=False`、`position_adjustment_enable=False`、
  无 protections 配置。
- 杠杆固定 1 倍；隔离保证金，爆仓由引擎模拟并单独统计。

### 4.3 结果读法

1. **24 个单元里只有 3 个净利为正**：high_vol 1d（+85.1）、mixed 1d（+37.0）、majors 30m（+51.3）。
2. **这 3 个正结果全部由 1~2 个币贡献**，不是组内普遍现象：
   - high_vol 1d：只有 11 个币产生交易，EVAA 用 2 笔贡献 65.7，占该单元净利的 77%。
   - mixed 1d：SYN **单笔**贡献 35.8，占 97%。
   - majors 30m：LAB 一个币 +76.5，而整单元净利只有 +51.3（占 149%），20 个币里只有 7 个为正。
3. **成本是决定性变量。** 毛利为正的单元有 9 个，净利为正的只有 3 个 —— 单边 0.1% 的手续费
   把 6 个单元从正翻负。手续费占起始资金的比例随周期单调上升：1d 约 0.1~0.2%，
   1h 约 3%，5m 约 32~41%，**1m 约 67~89%**。
4. **周期越短越差**，四个组一致：1m 全部亏损 92~95% 的资金，PF 0.17~0.57。
   这与信号频率直接相关（1m 单元 6700~8900 笔，几乎每笔都在同一根 K 线内反手）。
5. **资金费不是主要因素**：24 单元合计仅 -45.8 USDT，相对 5539.9 USDT 的手续费可忽略。
   各单元均为非零值，已核对不是"无持仓跨结算"导致的全零。
6. **1d 单元样本不足**：每单元只有 15~19 笔，且 8~11 笔是期末强平。
   1d 行的正负都不具统计力，不能据此下任何结论。
7. **多空基本对称**（除 1d 外各单元多空笔数几乎 1:1），说明亏损不是方向暴露，
   而是信号本身在扣费后不赚钱。

### 4.4 审计与残留风险披露

- **出场原因分布（全矩阵 55,677 笔）**：`reversal` 55,382、`force_exit` 292、
  `stop_loss` 2、`liquidation` 1。**没有任何 ROI、追踪止损或超时出场**，
  证实纯信号口径成立。
- **残留保护触发 3 笔**，全部是 1 倍空头被价格翻倍打穿：
  - majors 1d：BEAT 空头 2.623 → 5.219，`stop_loss`，-99.3%
  - high_vol 1h：US 空头 0.020149 → 0.040096，`stop_loss`，-97.9%
  - majors 15m：LAB 空头 7.303 → 13.969，`liquidation`，-93.1%

  这 3 个单元不是干净的纯信号结果：若没有引擎的 -99% 地板，它们会更差，
  因此这几格的数字**偏乐观**而非偏悲观。
- **期末未自然退出 292 笔**（`force_exit`），是样本边界处理不是策略出场；
  1d 单元里这类占比最高（15~19 笔中有 8~11 笔），已在第 6 点标注。
- **反手成交**：Pine 用一张反向单换向，Freqtrade 用"平仓 + 反向开仓"两笔。
  实测同根 K 线内完成换向的比例极高（如 1m 单元 8133/8170），说明引擎行为与 Pine
  的反手在时点上基本对齐，但仍是两笔订单、两次手续费。

### 4.6 1d 行的稳健性检验：月度均值为正是切月伪影（2026-09-05）

下面三项检验证明这是回测把样本切成月份造成的伪影，不是信号。

**(a) 1d 单元的出场里多数是月末强平，不是策略出场**

32 个 1d 单元中，`force_exit` 占比 **41% ~ 87%**（中位约 62%）。月末强制平仓相当于
一个隐藏的时间止损，系统性地截断了仍在恶化的趋势仓。1m 单元的强平占比接近 0，
所以这个偏差只污染 1d（1h/30m 次之）。

**(b) 去掉切月，连续跑 8 个月（币池固定为 2026-01 那份，2026-01-01 → 2026-09-01）**

## 5. 最终是否采用的结论

**结论日期**：2026-09-05（v2.1，基于 2026 年 1~8 月共 8 个完整月的全年矩阵；v1/v2 见 §5.4）

### 5.1 移植正确性：**验收通过**

- 源码取自 pine-facade 快照（MD5 `c27e4c2daa6dfe94e864495a71a44f96`），逐行对照实现。
- factor 固定为 1.75 时，`supertrend_dynamic` 的方向与 `pandas_ta.supertrend` 一致率 **0.9993**
  （BTC 1h 全样本，差异仅在预热区）。
- regime 锁存、滞回中间带、chop 闸门"卡住仓位而非平仓"的行为均按源码语义实现。
- `lookahead-analysis`：`has_bias = No`，无未来数据。
- 全年 441,299 笔的出场原因分布中只有 `reversal` 与 `force_exit`（外加 65 笔残留保护），
  证实没有隐含 ROI / 止损 / 超时出场。

### 5.2 策略信号：**不采用**

依据（以 §4.5 全年矩阵为准）：

1. **短周期完败**：15m / 5m / 1m 三行，四组八个月共 96 个单元，
   **盈利月份数 0**。1m 每月亏掉起始资金的 90~93%。
2. **中周期为负**：1h 均值 -4.0% ~ -8.5%/月，30m 均值 -2.8% ~ -5.9%/月，
   盈利月份数 1~4 / 8。少数亮眼单元（2026-03 high_vol 1h +20.2%）
   在同一格的其他月份不复现。
3. **1d 均值虽有两格为正（high_vol +1.97%、mixed +2.56%），但已被 §4.6 证伪**：
   1d 单元 41~87% 的出场是月末强平（隐藏时间止损）；去掉切月连续跑 8 个月，
   这两组变成 -37.8% 与 -41.0%、回撤约 50%；固定币池后按月切也是四组全负。
   该行的正收益来自逐月换池的选币规则，不是信号本身。
4. **成本是分界线而非借口**：192 个单元中毛利为正 72 个、净利为正仅 36 个。
   信号在毛口径下也只有四成单元为正，扣费后剩不到两成。这不是"费率略高"，
   是反手频率与单笔毛边际不匹配。
5. **四类币池不改变结论**：每个周期上四组符号一致；低波动组在短周期略好、
   高波动组在 1d 略好，都不足以翻转方向。
6. **多空对称亏损**，排除方向暴露解释。
7. 与作者原设计的关系：本阶段移除的只有仓位口径，**出场逻辑与原策略默认配置一致**
   （原默认本就无止损止盈）。因此不能用"删了作者的风控"来解释这个结果。
   若要检验作者开启 `useTrailing` 后的完整版本，需用 `TrendShiftRegime` 另立实验。

### 5.3 适用范围与限制

- 覆盖：Binance USDT 永续、2026-01 ~ 2026-08 共 8 个完整月、逐月独立冻结的四类币池、
  1d~1m 六个周期、单边 0.1%、1 倍杠杆、固定 50 USDT 名义仓位。
- 192 个单元**不是 192 个独立样本**：混合组与前三组重叠，同一币在多个周期重复出现，
  相邻月份的币池也部分重叠。这是探索性矩阵，不是样本外证明。
- 8 个月全部落在同一年，未覆盖 2025 年及更早的市场状态。

### 5.5 否决依据存档（避免重复探索）
