# 共用4槽：1倍杠杆 + 2%基础风险预算

## 结论

保持1倍杠杆、只把`risk_per_trade`从1%提高到2%，在四个刷新锚点上都显著提高了收益。收益中位数从`+65.31%`提高到`+141.76%`，最差收益从`+50.50%`提高到`+90.60%`；中位数回撤从`8.85%`提高到`16.33%`，最差回撤从`12.43%`提高到`20.20%`。

相对此前“2倍杠杆、所有名义风险严格翻倍”版本，本方案牺牲一部分收益，但中位和最差回撤更低，没有发生强平，PF也更高。对于500 USDT初期实盘，它是两种风险放大方式中更合理的候选。

## 实验口径

- 逐仓杠杆保持1倍；硬止损继续为`-35%`，ATR止损和移动止损完全不变。
- 基础`risk_per_trade`由1%提高到2%。
- 40%权益的单仓名义上限保持不变，因此原本已经触及上限的低ATR交易不会机械翻倍。
- 持续放量多头仍使用2.0倍标签倍率，目标风险最高约4%；高成交量空头仍使用1.75倍，目标最高约3.5%；延伸多头约1%，普通scout空头约0.5%。以上都继续受40%单仓上限约束。
- 固定最小仓位scout仍保持交易所最小仓位，因为它不经过`risk_per_trade`风险公式。
- 币池、信号、手续费、500 USDT本金和自然退出规则不变。
- 回测引擎建议槽位设为100以绕过下单前的Binance档位查询限制；策略入口硬限制实际持仓4笔，审计确认实际最大并发均为4。

## 路径和资金占用

- 8/15/22日三组的全部入场和平仓路径与1%版本逐笔一致。
- 1日组少了两笔7月21日的最小仓位scout：1000PEPE多头和SXT空头；它们在1%版本合计亏损约`0.16 USDT`。缺失原因是1倍下更高保证金占用，而不是信号改变。
- 平均单笔保证金从四组的`28.66/22.63/22.88/18.78`提高到`63.81/47.26/47.11/32.32 USDT`。
- 四组实际最大并发均为4，杠杆全部为1倍，强平为0。

## 阶段判断

- 若希望在不引入杠杆强平风险的前提下明显提高收益，1倍杠杆、2%基础风险预算优于直接使用2倍杠杆。
- 代价是资金占用更高，并且最差历史回撤已达到约20%；实盘还需预留滑点和同时止损的额外空间。
- 该版本可以作为高风险实盘候选，但不应再从历史最高相位的`+345.86%`外推收益；更应参考四锚点中位数与最差回撤。
- 本轮到此停止，不继续在已观察月份上提高风险或修改40%单仓上限。
