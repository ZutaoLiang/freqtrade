# 1倍杠杆、2%风险预算：逐月独立回测

## 结论

将每个自然月都重置为500 USDT独立回测后，2月至7月的24个完整月/刷新锚点样本中有17个盈利，盈利占比70.8%；月收益中位数为`+16.09%`，最差为`-6.56%`，最大回撤中位数为`7.59%`，最差为`14.61%`。

结果支持“1倍杠杆 + 2%基础风险预算”具有收益能力，但没有支持“任意刷新时点都能稳定盈利”：只有3月和7月的四个刷新锚点全部盈利。2月与6月的跨锚点月收益中位数分别为`-0.85%`和`-2.21%`，币池刷新相位仍是目前最大的结果不稳定来源。

8月仅覆盖1日至13日，不是完整月；四锚点收益中位数为`-6.89%`，仅1组盈利。

## 回测口径

- 策略：共用4槽，月度核心币池 + 周度Top2增量候选。
- 每个自然月重新以500 USDT启动独立回测，不继承上月资金和仓位。
- 基础`risk_per_trade = 2%`，逐仓杠杆固定1倍，单仓名义上限40%。
- 月内币池刷新和自然退出规则保持不变；仅回测区间最后一根K线会由引擎平掉尚未结束的仓位。
- 手续费按单边0.07%；1/8/15/22日四组月度刷新锚点全部测试。
- 2月至7月是完整月；8月区间为8月1日至8月13日结束。

## 行情方向贡献

- 3月主要由空头贡献：四锚点平均月收益`+19.14%`，其中空头平均贡献约`+18.08`个百分点。
- 4月主要由多头贡献：四锚点平均月收益`+48.42%`，其中多头平均贡献约`+49.64`个百分点。
- 5月多空均有贡献，多头约`+9.42`个百分点、空头约`+4.86`个百分点。
- 7月再次主要由空头贡献，空头平均约`+20.10`个百分点，多头约`-2.27`个百分点。
- 8月上半月多空两侧平均都亏损，说明弱表现不是只由某一个方向开关造成。

这说明放开空头是有效的：3月和7月两个跨刷新锚点最稳定的盈利月份，都主要依靠空头行情。

## 月末边界影响

28组回测共有76笔仓位在月末边界由引擎平仓，合计贡献`403.13 USDT`。其中影响最大的是4月：四组月末边界平仓合计贡献`241.93 USDT`，使四组收益中位数由剔除边界仓位利润后的约`+49.53%`提高到`+65.25%`；6月也有较明显影响。

这些利润是月末时点的真实浮盈/浮亏，但当前实盘规则并不会在月末强制平仓，因此逐月独立结果适合判断“当月信号质量”，不应代替此前允许仓位自然结束的连续回测结果。
